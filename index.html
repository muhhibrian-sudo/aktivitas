🌐 Cara Onlinekan di GitHub Pages & Pakai Python

1. Cara Onlinekan Gratis di GitHub Pages

  1. Buka github.com/new lalu buat repository baru (misal: tracer-servis-toko).
  2. Upload file yang ada di folder ini: index.html, style.css, app.js, data.js, app.py, dan parse_data.py.
  3. Buka menu Settings ➔ Pages di repository GitHub Anda, lalu pada bagian Branch pilih main dan klik Save.
  4. Dalam 1 menit, aplikasi langsung online di https://username-anda.github.io/tracer-servis-toko/ dan bisa dibuka dari HP/komputer mana saja!

2. Cara Menjalankan dengan Python di Komputer Toko

Jalankan perintah berikut di terminal/CMD pada folder ini:

python app.py

Saat dijalankan dengan python app.py, setiap kali teknisi menambah unit atau mengupdate progres di browser, Python otomatis menyimpan perubahan langsung ke file data_service.json, data.js, dan raw_data.csv!
